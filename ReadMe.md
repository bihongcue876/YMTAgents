## 源代码快速启动

环境：Python 3.14 + [uv](https://docs.astral.sh/uv/)。

```powershell
# 安装依赖（创建 .venv 并锁定 uv.lock）
uv sync

# 启动
uv run python -m app

# 或指定文件启动
python src/app/main.py
```

已激活虚拟环境时（`.venv\Scripts\Activate.ps1`），也可直接：

```powershell
python -m app

# 或指定文件启动
python src/app/main.py
```
